# Замеры стола для модели Snake Shot

Исходные измерения пользователя от 19.10.2026. Единицы — сантиметры.
Это справочник измерений, **не** параметры текущей геометрии визуализатора. Не менять расчётную модель без уточнения неоднозначностей.

| Параметр | Значение |
|---|---:|
| Ширина ворот | 21 |
| Ширина фигурки игрока | 2.5 |
| Диаметр мяча | 3.5 |
| Линия ворот → линия вратаря | 3.5 |
| Линия ворот → линия защиты (двойки) | 18.5 |
| Линия ворот → линия тройки | 33.5 |
| Расстояние между защитниками, центр–центр | 23.5 |
| Смещение точки контакта с мячом наклоном фигурки относительно центра штанги | в пределах 5 |
| Линия ворот → точка нахождения мяча на тройке в пин-позиции | 29 |

## Уточнить перед внедрением
1. 23.5 см — центры двух фигурок на одной штанге двойки или другое измерение?
2. 5 см — максимальное смещение в каждую сторону (±5) или суммарный диапазон?
3. 29 см — расстояние от линии ворот до центра мяча в пин-позиции?
4. Для ширины ворот и дистанций — какие именно физические кромки/центры использовались при измерении?

Расчётное отношение ширины ворот к диаметру мяча: 21 / 3.5 = 6. Текущая модель использует условные 5.8 диаметра.
