# Замеры стола для модели Snake Shot

Исходные измерения пользователя от 19.10.2026. Единицы — сантиметры.
Это справочник измерений, **не** параметры текущей геометрии визуализатора. Не менять расчётную модель без уточнения неоднозначностей.

| Параметр | Значение |
|---|---:|
| Ширина ворот | 21 |
| Ширина фигурки игрока | 2.5 |
| Диаметр мяча | 3.5 |
| Линия ворот → линия вратаря | 3.5 |
| Линия ворот → линия защиты (двойки) | 18.5 |
| Линия ворот → линия тройки | 33.5 |
| Расстояние между центрами двух фигурок на одной штанге двойки | 23.5 |
| Смещение точки контакта с мячом наклоном фигурки относительно центра штанги | ±5 (5 вперёд, 5 назад) |
| Линия ворот → центр мяча на тройке в пин-позиции | 29 |

## Уточнить перед внедрением
Подтверждено пользователем: 23.5 см между центрами двух фигурок на одной штанге двойки; наклон даёт ±5 см (вперёд и назад); 29 см до центра мяча в пин-позиции.

Остаётся уточнить при необходимости: для ширины ворот и дистанций — какие именно физические кромки/центры использовались при измерении.

Расчётное отношение ширины ворот к диаметру мяча: 21 / 3.5 = 6. Текущая модель использует условные 5.8 диаметра.
